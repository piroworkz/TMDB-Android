## Summary

Implement session-scoped favorites for Movies and TV Shows with immediate UI feedback. Favorites are toggled from media cards, surfaced in a dedicated Favorites screen with a Movies/TV Shows filter, and cleared on session end (guest expiration or logout). Technically, this extends existing `feature/media` entities and Room storage with an `isFavorite` flag, integrates session state from `auth_domain`, and wires UI state to reflect favorite changes immediately.

**Constraints**: No server sync; no new dependencies; favorites cleared on session end

## Technical Approach (How)

### 1) Domain layer (media_domain)
- Extend `Media` with an `isFavorite: Boolean` flag.
- Use `Catalog` to derive `MediaType` where needed (as per `Catalog.mediaType`).
- Add use cases in `media_domain`:
  - `ObserveFavoriteMedia(mediaType, scope): Flow<PagingData<Media>>`
  - `ToggleFavorite(mediaId, mediaType)`
  - `ClearFavorites()`

### 2) Data layer (media_data)
- Persist `isFavorite` in Room by extending `RoomMedia` with a default `false`.
- Add a **new `FavoritesDao`** that operates on the existing `MediaDatabase`.
- Add DAO query to return a PagingSource filtered by `isFavorite = true` and `mediaType`.
- Update the **local → domain mapping** (`RoomMedia` → `Media`) to propagate `isFavorite` into existing lists; remote mapping remains unchanged.
- Create a **`FavoritesRepository`** that implements the favorites use cases (observe, toggle, clear), similar in style to `AuthenticationRepository` in auth_data.
- No migrations required per project constraints (app not published).

### 3) Session lifecycle integration (auth_domain)
- Use `ObserveSession` to track active session state.
- Use `CloseSession` as the single path to end a session.
- When session ends (guest expiration or logout), invoke `ClearFavorites`.
- Ensure favorites observers react to session changes (lists clear immediately).

### 4) UI layer (media_ui)
- Add Favorites screen with Movies/TV Shows filter and empty/loading/error states.
- Build ViewModel that combines:
  - favorites lists by type (from `ObserveFavoriteMedia`)
  - UI filter selection
  - error surface for toggle failures
- Add heart overlay to media cards in existing grids:
  - Use `Media.isFavorite` already present in paged lists.
  - Toggle via `ToggleFavorite` use case.
- Any new shared UI resources (icons, strings, colors) should be added in `feature/core` per project rule.

### 5) Navigation and app wiring
- Add drawer entry for Favorites.
- Register navigation route and hook into app-level nav graph.
- Wire Koin modules across media/auth as needed (no new feature module).

### 6) Error handling and UX behavior
- Toggle errors show non-blocking messages; UI state remains correct.
- Favorites screen shows retry on load failure (if applicable to local storage).

## Data Flow (End-to-End)

- **Media grids**: existing paged queries return `Media` with `isFavorite`; UI binds heart state directly.
- **Favorites screen**: `ObserveFavoriteMedia(mediaType, scope)` returns a paged flow filtered by `isFavorite = true`.
- **Toggle**: `ToggleFavorite` updates Room; flows update automatically to refresh grids and Favorites screen.
- **Session end**: `CloseSession` triggers `ClearFavorites`; observers emit empty lists.
